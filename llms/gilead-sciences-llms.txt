# Gilead Sciences

> Gilead Sciences is a research-based biopharmaceutical company that discovers, develops, and
> commercializes innovative therapeutics in areas of unmet medical need including HIV, viral
> hepatitis, oncology, and inflammatory diseases. Gilead publishes **no public API, developer
> portal, or machine-readable API contract**. What it does publish is a first-party open-source
> software estate on GitHub — the "Good Statistical Monitoring" (gsm) suite of R packages for
> risk-based quality management of clinical trials. This file was generated by API Evangelist from
> the public profile at all/gilead-sciences; it is a third-party index, not a Gilead document.

## APIs

No public API. As of 2026-09-12 no OpenAPI, Swagger, GraphQL SDL, AsyncAPI, gRPC/Protobuf or WSDL
contract is published on any host this profile knows, and no MCP server or A2A agent card is served.
`api.gilead.com` resolves but answers HTTP 200 with the same generic "Resource not Found" page for
every path, including paths that cannot exist; `developer.gilead.com`, `developers.gilead.com`,
`apis.gilead.com` and `portal.gilead.com` do not resolve.

## Open source

- [Gilead-Public on GitHub](https://github.com/Gilead-Public): Gilead's approved public repository organization (19 public repos).
- [Gilead-BioStats on GitHub](https://github.com/Gilead-BioStats): Gilead biostatistics repositories (5 public repos).
- [gsm](https://github.com/Gilead-Public/gsm): Good Statistical Monitoring meta-package (R, Apache-2.0).
- [gsm.core](https://github.com/Gilead-Public/gsm.core): Analytics framework for gsm metrics and workflows.
- [gsm.mapping](https://github.com/Gilead-Public/gsm.mapping): Data mapping framework for gsm.
- [gsm.kri](https://github.com/Gilead-Public/gsm.kri): Key risk indicator workflows, visualization and reporting.
- [gsm.reporting](https://github.com/Gilead-Public/gsm.reporting): Reporting data model for gsm reports.
- [gsm.datasim](https://github.com/Gilead-Public/gsm.datasim): Synthetic clinical trial data generation for RBQM.
- [gsm.viz](https://github.com/Gilead-Public/gsm.viz): Web-based data visualization for risk-based monitoring (JavaScript).
- [qcthat](https://github.com/Gilead-Public/qcthat): Quality control framework for R packages used in clinical trials.
- [gsm.app](https://github.com/Gilead-BioStats/gsm.app): Shiny application with drill-down for gsm assessments.
- [clindata](https://github.com/Gilead-BioStats/clindata): Synthetic clinical data for testing and development.
